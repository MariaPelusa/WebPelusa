## Documentación

### Diagrama UML - Aplicación de Colaboración para Artistas

Se ha desarrollado un diagrama UML completo para una aplicación de colaboración entre artistas. La documentación completa está disponible en:

📁 [docs/uml/README.md](docs/uml/README.md)

El diagrama incluye las siguientes funcionalidades:
- ✅ Registro de usuarios artistas
- ✅ Perfiles públicos con galería de imágenes
- ✅ Sistema de mensajería privada entre artistas
- ✅ Localización de artistas mediante mapa
- ✅ Tablón de anuncios para proyectos colaborativos
- ✅ Sistema de solicitudes para unirse a proyectos

Ver el diagrama PlantUML: [docs/uml/artist-collaboration-app.puml](docs/uml/artist-collaboration-app.puml)
